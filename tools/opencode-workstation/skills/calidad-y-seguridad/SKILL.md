---
name: calidad-y-seguridad
description: Revisar cambios, regresiones, privacidad, permisos o preparar una entrega técnica.
---

Leer diff y el flujo afectado. Examinar errores, validación de entrada, autorización, IDOR, inyección, abuso, secretos, PII, dependencias, concurrencia y rollback. Distinguir un hallazgo demostrado de una sospecha. Priorizar evidencia reproducible con archivo. Para UI verificar teclado, foco, contraste, móviles y estados fallidos. Ejecutar las pruebas relevantes y registrar las que faltan. En Victoriosas npm run verify y CI validate/postgres del SHA final cuando corresponda. No fabricar resultados ni cambiar pruebas para ocultar fallos.
